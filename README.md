# Predicting Peak Pressure in BLEVE Incidents
This repository contains my university Machine Learning assignment, where the goal was to build a model that predicts the peak pressure generated during a BLEVE (Boiling Liquid Expanding Vapour Explosion) scenario.

Project Summary

Students were provided with training and test datasets from a simulated 3D BLEVE environment that included tank properties, thermodynamic data, obstacle dimensions, and sensor positions.

The task was to:
- Clean and preprocess the dataset
- Engineer useful features
- Train multiple machine learning models
- Evaluate performance and submit predictions in a Kaggle-style competition

The project achieved a 90% grade, with the best model reaching a score of 0.22265, mainly due to strong feature engineering and the use of ensemble methods.
